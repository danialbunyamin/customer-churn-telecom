# customer-churn-telecom
Customer churn analysis using Python and machine learning

## 📌 Project Overview

This project analyzes customer churn in a telecommunications company
to identify factors that influence customer churn and provide
data-driven insights that can support customer retention strategies.
Customer churn is one of the major challenges faced by telecommunications companies. 
Understanding why customers leave can help companies develop more effective customer 
retention strategies and reduce potential revenue loss.

In this project, I analyzed telecommunications customer data to identify factors associated 
with customer churn and developed machine learning classification models to predict customer churn.

The project combines **Exploratory Data Analysis (EDA)**, **data preprocessing**, 
**class imbalance handling**, and **machine learning** to generate both analytical 
and business insights.

## 🎯 Objectives

The main objectives of this project are:

- Understand customer churn patterns
- Identify factors associated with customer churn
- Perform exploratory data analysis (EDA)
- Build machine learning models to predict customer churn
- Compare model performance before and after oversampling

## 📊 Dataset

The dataset contains customer information related to:

- Customer demographics
- Services subscribed
- Contract information
- Payment methods
- Monthly charges
- Total charges
- Customer churn status

## 🔎 Exploratory Data Analysis

The analysis includes:

- Data cleaning and preprocessing
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Churn distribution
- Customer characteristics related to churn

## 🤖 Machine Learning

Several classification models were evaluated, including:

- Logistic Regression
- Decision Tree
- Random Forest

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## ⚖️ Handling Class Imbalance

Because customer churn data may contain an imbalance between churn
and non-churn customers, oversampling was applied to the training data.

Model performance was compared before and after oversampling.

## 📈 Key Findings

The analysis identified several customer characteristics that were
associated with differences in churn behavior.

Machine learning models were also compared to determine their
performance in predicting customer churn.
